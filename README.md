# 💰 Financial Tracker App

A Flutter-based personal finance management application that helps users track their income, expenses, and overall balance. The application provides a clean, modern, and user-friendly interface for managing daily financial transactions.

## 🚀 Features

### 🔐 User Authentication
- User Registration (Sign Up)
- User Login
- Username Validation
- Secure Local Storage using SharedPreferences

### 💵 Income Management
- Add Income Transactions
- View Income History
- Categorize Income Records
- Delete Income Entries

### 💸 Expense Management
- Add Expense Transactions
- View Expense History
- Categorize Expense Records
- Delete Expense Entries

### 📊 Financial Dashboard
- Real-Time Balance Calculation
- Total Income Tracking
- Total Expense Tracking
- Hide/Show Balance Feature

### 👤 User Profile
- Profile Management
- Personalized User Experience

### 💾 Local Storage
- Data Persistence using SharedPreferences
- User-Specific Transaction Records
- Offline Functionality

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/GowthamsundarS/Montra_The_Money_Tracker.git
```

### Navigate to Project Directory

```bash
cd montra
```

### Install Dependencies

```bash
we have used
image_picker: ^1.2.2
shared_preferences: ^2.5.3

add these to the pub.dev and run this command 
flutter pub get
```

### Run the Application]
```bash
flutter run
```

---

## 📦 Build APK

```bash
flutter build apk --release
```

Generated APK Location:

```text
build/app/outputs/flutter-apk/app-release.apk
```
